# Security Policy

## Supported Versions

We release security updates for the latest stable version of RandMatQuGeA. Older versions are not actively maintained and may contain unpatched vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| >=1.8.x   | :white_check_mark: |
| < 1.8   | :x:                |

## Reporting a Vulnerability

We take security issues seriously. If you discover a vulnerability in RandMatQuGeA, please report it privately so that we can address it before public disclosure.

### How to Report

1. **Do not** open a public issue.
2. Send an email to [richard@richardsblogs.com](mailto:richard@richardsblogs.com) with the subject prefix `[SECURITY]`.
   - Include a clear description of the vulnerability, steps to reproduce, and any relevant code snippets or screenshots.
   - If possible, provide a suggested fix or mitigation.

### What to Expect

- You will receive an acknowledgment within one week.
- We will investigate the report and provide updates as we work on a fix.
- Once a fix is ready, we will coordinate a release and disclose the vulnerability responsibly, giving you credit unless you prefer anonymity.

Thank you for helping keep RandMatQuGeA secure.
